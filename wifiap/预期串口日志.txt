排障对照表（烧录后搜不到热点时，看串口最后停在哪一行）
1. 完全没有 [WIFIAP] 行
   -> 固件没跑：烧错包 / 烧录后没再按 RESET / 串口选错或波特率不对 /
      IDE 重新 Kconfig 时把 support WIFIAP Sample 取消后没重新 build。
2. 只有 Start 与 BOOT CHECK，没有 WiFi init OK
   -> WiFi host 未初始化：改烧 *_all.fwpkg（含 ws63_all_nv.bin），重新上电。
3. 有 WiFi init OK，但 wifi_softap_enable ret 非 0 / 出现 FATAL
   -> WiFi device 侧或 NV 校准数据异常：重新烧 all.fwpkg，必要时 rebuild 后再烧。
4. 有 "SSID H is now broadcasting" 但手机列表里看不到 H
   -> 手机侧：手动「添加网络」填 H / 12345678 / WPA2-PSK；只搜 2.4 GHz；
      在列表底部找被折叠的「无互联网」热点；关闭 WLAN+ 智能切换。
5. 出现 SoftAp start success，但连上后没有 STA JOIN
   -> 密码或加密方式不匹配；或手机自动切回移动数据，先关移动数据再连。

验收要点：
1. 手机 WLAN 列表中出现热点 H（WPA2，2.4 GHz 6 信道）。
2. 输入密码 12345678 后状态变为「已连接」，手机获得 192.168.63.x 地址。
3. 串口出现「手机连接热点成功 / PHONE CONNECTED HOTSPOT SUCCESS」。
4. 串口出现 [DHCP] phone IP=... 与 LINK UP，说明 DHCP 与链路均正常。

烧录提示：
1. 请烧录 wifiap_lab/firmware/ws63-liteos-app_all.fwpkg
   （或 SDK 的 output/ws63/fwpkg/ws63-liteos-app/ws63-liteos-app_all.fwpkg），
   这个包才包含 Bootloader + App + NV 校准数据 + 分区表；
   不要只烧单个 ws63-liteos-app.bin，也不要用 load_only.fwpkg 代替 all.fwpkg。
2. HiSpark Studio 出现 "Connecting, please reset device..." 时，
   必须人工按一下开发板 RESET 键；烧录完成后再按一次 RESET 让新固件运行。
3. 若 IDE 里重新点过 Kconfig / Save，请确认 Application → Enable the Sample of peripheral
   下的 support WIFIAP Sample 仍被选中，再 build / rebuild，否则固件里不会有 wifiap 代码。
